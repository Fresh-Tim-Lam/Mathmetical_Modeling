# 问题3 结果与分析（相关性建模，在问题2 基础上）

> 目标：考虑作物间**可替代/互补性**（需求侧）与**销量-价格-成本相关性**后，重求 2024~2030
> 最优方案，并与问题2 方案比较。相关性结构定义见《问题3假设与文献.md》假设 A/B；
> 求解算法与收敛性见《问题建模与求解.md》§4/§6.1。
>
> 数据出处：`outputs/p3_compare.csv`（评估层）、`outputs/p3_area_diff.csv`（方案差异）、
> `outputs/区间灵敏度.csv` 等（§6 系列表）。

## 1. 求解口径

- 决策：全量连续权重 DE（32×80），逐年级进；问题3 目标 = **SAA 期望收益**（搜索层每方案
  MC 采样 $N=2000$，CRN 逐年缓存样本）；
- 终值评估：**同一组 CRN 样本 $N=20000$** 重估问题2/问题3 方案（消除采样噪声，可比）；
- 相关矩阵：每作物块内 $\rho_{dp}=0.4,\rho_{dc}=0.3,\rho_{pc}=0.2$；块间 6 组互补对 $\rho\in[0.25,0.3]$、
  替代对 $\rho\in[-0.4,-0.2]$，PSD 修正后 Cholesky 采样；价格随机化区间见假设 C。
- 约束违规：重茬 0、豆类窗口 0、编码规则 0。

## 2. 核心结果

### 2.1 总览（评估层 $N=20000$，CRN 同样本）

| 指标 | 问题2 方案 | 问题3 方案 | 变化 |
|---|---|---|---|
| 相关 MC 期望 / 万元 | 4022.67 | **4032.19** | **+9.52（+0.24%）** |
| 独立求积期望（Q2 框架）/ 万元 | 3994.55 | 4004.01 | +9.46（+0.24%） |
| 合计标准差 / 万元 | 40.54 | 41.11 | +0.57（+1.4%，基本持平） |
| CVaR$_5$ / 万元 | 3940.08 | **3948.36** | **+8.28** |

- 两种评估框架（相关 MC 与独立求积）下问题3 方案均比问题2 高 **0.24%**——增益来自方案本身，
  与评估框架无关（非 MC 噪声）；
- **期望小幅提升 + 尾部（CVaR）改善 + 风险（std）基本持平**：相关性信息对方案是"免费午餐"式的
  边际增益，未牺牲稳健性。

## 3. 方案差异分析（vs 问题2，`p3_area_diff.csv`）

- 差异规模：**2024 年方案完全一致**（相关性尚未产生分化）；2025~2029 为主要调整期；
  2030 局部调整（滚动约束收敛）。总差异记录 197/275 处（含小幅数值波动），面积差 ≥5 亩的
  实质性调整如下：

**结构特征**：
1. **调整集中于 A/B/C 露天粮食区**（黄豆/黑豆/绿豆/小麦/玉米/谷子/莜麦/大麦），大棚、水浇地
   蔬菜区仅单年小幅微调（≤2.5 亩）——相关性对期望的边际增益主要由**粮食需求互替结构**贡献；
2. 调整方向多为"**豆类 ↔ 主粮**"再平衡（黑豆→小麦、绿豆→小麦、谷子↔小麦等），恰与模型中
   定义的替代需求对（小麦/玉米 ↔ 豆类 1~5，$\rho=-0.2$）一致——负相关需求对要求两类作物
   种植比例重新搭配以对冲需求同涨同跌；
3. 替代对内部（谷子/高粱/黍子/大麦、食用菌组）与互补对（大白菜↔萝卜等）在同季内联动调整，
   与相关符号一致（互补作物同增减、替代作物反向增减）。

## 4. 稳健性与误差分析摘要（详见《问题建模与求解.md》§6）

| 维度 | 结论 |
|---|---|
| MC 收敛（误差分析） | $N\ge2000$ 期望稳定，$N=20000$ 时 SE=0.29 万；搜索层 SAA 误差可忽略 |
| 求积阶数 | n_quad=16/24/40 差 <0.01 万 |
| 相关强度灵敏度（ρ ±50%） | 期望变化 ≤0.01%——相关性数值假设对结论不敏感 |
| 不确定区间半宽（±50%） | 产量影响最大但 <0.5%，其余更小 |
| 分布假设鲁棒性 | 问题2/3 方案四分布极差均 0.7%，问题3 各分布下均高约 10 万 |
| 相关结构误设（R=I vs R） | 期望差 <0.01 万，仅 std 放大 4 万——真实无相关也不损失期望 |
| 随机种子 | MC 种子波动 0.02%；DE 种子 seed=1 vs 基准差 0.03% |

## 5. 结论

1. 在问题2 基础上引入需求侧替代/互补与销量-价格-成本相关性后，最优期望收益由 4022.67 提升至
   **4032.19 万元（+0.24%）**，尾部风险 CVaR$_5$ 改善 **+8.3 万元**，整体风险（std）基本持平；
2. 方案变化集中在露天粮食区的"豆类↔主粮"再平衡，方向与替代需求对结构一致，体现了相关结构
   对种植配比的实际影响；
3. 该增益对相关强度数值、分布假设、随机种子均稳健（§4），结论可靠。
