# 2024年高教社杯C题：基于纯连续编码与差分进化的种植策略优化模型

## 第一部分：问题理解与核心挑战

### 1.1 问题本质

这是一个**7年（2024-2030）序贯决策优化问题**，决策空间由54块不同类型地块构成，每块地每季可从特定作物集合中选择种植，并分配连续面积。核心难点在于：

| 挑战类型 | 具体描述 |
| :--- | :--- |
| **连续-离散混合** | 既需要选择“种什么”（离散），又需要决定“种多少”（连续） |
| **时序耦合** | 重茬约束（t年与t-1年互斥）、豆类轮作（3年滑动窗口） |
| **跨季耦合** | 水浇地第一季若种水稻，第二季必须休耕 |
| **全局耦合** | 每种作物的全乡总产量受预期销售量（Demand）约束，超出部分滞销或半价 |
| **管理约束** | 每种作物每季占地块数不宜超过5块 |

## 第二部分：变量编码设计（核心创新）

### 2.1 编码哲学：用连续变量的“有无”代替离散的“选择”

传统思路需要为每个地块-季节单元编码“作物ID”（离散）+“面积比例”（连续），属于混合整数问题。我们采用**全量连续编码**：

> **对每个地块-季节单元允许种植的每一种作物，直接赋予一个连续权重。权重大于0表示“选择并种植”，权重等于0表示“不选择”。**

这样，原本需要0-1离散变量和连续面积变量两个层次的问题，被**压缩为单一层次的连续变量**——变量的数值本身同时承载了“是否选择”和“种多少”的信息。

## 第三部分：解码器设计（将权重翻译为合法方案）

解码器是这整套方案的核心，负责将任意个体（1054个实数）翻译成**物理上可执行、数学上合法**的种植方案。

### 3.1 通用解码流程

```python
def decode_individual(individual, year, history):
    """
    输入：
      - individual: 长度为1054的连续向量
      - year: 当前年份
      - history: 前两年的种植记录（用于重茬和豆类检查）
    输出：
      - planting_plan: 该年54块地×2季的详细种植面积
    """
    result = {}
    idx = 0  # 当前读取位置
    
    # 1. 处理旱地（A/B/C类，26块，每块15个权重）
    for plot in A_BC_plots:
        weights = individual[idx:idx+15]  # 粮食1~15
        idx += 15
        result[plot]['Q1'] = decode_dryland(weights, plot.area, history, plot)
        result[plot]['Q2'] = {}  # 休耕
    
    # 2. 处理水浇地（D类，8块）
    for plot in D_plots:
        # 第一季：18个权重（水稻16 + 蔬菜17~34）
        weights_q1 = individual[idx:idx+18]
        idx += 18
        # 第二季：3个权重（根菜35~37）
        weights_q2 = individual[idx:idx+3]
        idx += 3
        # 核心：水浇地隐式模式切换
        result[plot]['Q1'], result[plot]['Q2'] = decode_waterland(
            weights_q1, weights_q2, plot.area, history, plot
        )
    
    # 3. 处理普通大棚（E类，16块）
    for plot in E_plots:
        weights_q1 = individual[idx:idx+18]  # 蔬菜17~34
        idx += 18
        weights_q2 = individual[idx:idx+4]   # 食用菌38~41
        idx += 4
        result[plot]['Q1'] = decode_vegetable(weights_q1, plot.area)
        result[plot]['Q2'] = decode_mushroom(weights_q2, plot.area)
    
    # 4. 处理智慧大棚（F类，4块）
    for plot in F_plots:
        weights_q1 = individual[idx:idx+18]  # 蔬菜17~34
        idx += 18
        weights_q2 = individual[idx:idx+18]  # 蔬菜17~34
        idx += 18
        result[plot]['Q1'] = decode_vegetable(weights_q1, plot.area)
        result[plot]['Q2'] = decode_vegetable(weights_q2, plot.area)
    
    return result
```

### 3.2 面积归一化（软约束）

对于任意一组权重 \( w = [w_1, w_2, ..., w_N] \)：

1. **裁剪**：\( w_i \leftarrow \max(0, w_i) \)（负数视为0）
2. **归一化**：\( r_i = w_i / \sum_{j=1}^N w_j \)（若总和为0，则全部休耕）
3. **面积分配**：\( area_i = r_i \times S_{plot} \)

### 3.3 水浇地“隐式模式切换”（核心创新）

这是整个编码中最精妙的部分——**无需额外的Mode基因，仅凭水稻权重的正负决定全年模式**：

```python
def decode_waterland(weights_q1, weights_q2, area, history, plot):
    # weights_q1: [水稻(16), 蔬菜17, 蔬菜18, ..., 蔬菜34]
    rice_weight = weights_q1[0]  # 第一个位置是水稻
    
    if rice_weight > 0:
        # ===== 模式A：单季水稻 =====
        # 第一季：只种水稻，面积=100%
        q1_result = {16: area}
        # 第二季：强制休耕（所有权重置零）
        q2_result = {}
        # 记录该地块本年为“水稻模式”，供明年查重茬
        return q1_result, q2_result, 'rice_mode'
    else:
        # ===== 模式B：两季蔬菜 =====
        # 第一季：从蔬菜17~34中分配面积
        veg_weights = weights_q1[1:]  # 去掉水稻位置
        q1_result = normalize_and_allocate(veg_weights, area, valid_crops=17~34)
        # 第二季：从根菜35~37中分配面积（强制最多1种）
        q2_result = normalize_and_allocate_max1(weights_q2, area, valid_crops=35~37)
        return q1_result, q2_result, 'veg_mode'
```

> **关键洞察**：进化算法不需要“理解”水稻和蔬菜是互斥的。它只需要尝试把水稻权重调高或调低。如果水稻权重高，解码器自动切到单季稻模式；如果水稻权重为0，解码器自动切到两季菜模式。**模式切换是解码器的功能，不是进化算法的职责。**

### 3.4 硬约束修复机制

在解码过程中，如果检测到以下情况，执行强制修复：

| 约束类型 | 检测条件 | 修复操作 |
| :--- | :--- | :--- |
| **重茬（同季）** | 本季作物与上一季该地块作物相同 | 将该作物权重强制置零，重新归一化 |
| **重茬（跨年边界）** | 今年第一季与去年第二季作物相同 | 同上 |
| **豆类轮作** | 连续3年该地块未种豆类（1~5,17~19） | 强制将本季面积最大的作物替换为豆类 |
| **分散管理** | 某作物本季占用>5块地 | 在分配时限制，超过5块则不再分配该作物 |
| **水浇地第二季** | 检测到多种根菜同时分配 | 保留权重最大的，其余置零 |

## 第四部分：适应度函数（问题一的利润计算）

### 4.1 适应度函数的输入输出

- **输入**：一个解码后的完整7年种植方案（54块地 × 2季 × 7年）
- **输出**：该方案的**7年总利润**（作为进化选择的依据）

### 4.2 单年单作物利润计算

对于第 \( t \) 年、第 \( j \) 季、作物 \( k \)：

1. **汇总全乡总产量**：
   \[
   Total_{t,j,k} = \sum_{i=1}^{54} \text{亩产量}_{i,j,k} \times \text{种植面积}_{i,t,j,k}
   \]

2. **销售量计算**（两种情况）：

   - **情况一（滞销）**：
     \[
     Sold_{t,j,k} = \min(Total_{t,j,k}, Demand_{j,k})
     \]
     \[
     Profit_{t,j,k} = Sold_{t,j,k} \times Price_{j,k} - \sum_i Cost_{i,j,k} \times Area_{i,t,j,k}
     \]

   - **情况二（半价）**：
     \[
     Sold_{t,j,k} = \min(Total_{t,j,k}, Demand_{j,k})
     \]
     \[
     Excess_{t,j,k} = \max(0, Total_{t,j,k} - Demand_{j,k})
     \]
     \[
     Profit_{t,j,k} = Sold_{t,j,k} \times Price_{j,k} + Excess_{t,j,k} \times 0.5 \times Price_{j,k} - \sum_i Cost_{i,j,k} \times Area_{i,t,j,k}
     \]

### 4.3 硬约束罚分

| 违反项 | 罚分（从利润中扣除） |
| :--- | :--- |
| 重茬（同季或跨年边界） | 1e9（相当于判死） |
| 连续3年未种豆类 | 1e8 |
| 某作物占用>5块地 | 1e6 + 超出块数 × 1e5 |

### 4.4 稀疏性奖励（可选）

为避免所有作物都被分配微量面积，可加入：
\[
\text{稀疏惩罚} = \alpha \times \sum_{单元} (\text{该单元非零权重个数})
\]
其中 \( \alpha \) 取较小值（如 50~100 元/种），引导进化算法收敛到稀疏解。

## 第五部分：差分进化算法设计

### 5.1 为什么选用差分进化（DE）？

| 特征 | GA | DE |
| :--- | :--- | :--- |
| 适用问题 | 离散/混合 | **纯连续优化** |
| 收敛速度 | 较慢 | **快（向量差分）** |
| 参数敏感性 | 高（交叉率、变异率） | **低** |
| 高维性能（1000+） | 差 | **优** |

我们的个体是 **1054 维连续向量**，DE是绝对首选。

### 5.2 标准DE/rand/1/bin策略

**初始化**：
\[
x_{i,0} = LB + rand(0,1) \times (UB - LB), \quad i=1,2,\dots,NP
\]
其中 \( LB=0 \)，\( UB=S_{plot} \)（该变量对应的地块面积，不同变量上界不同）。

**变异**（生成突变向量）：
\[
v_{i,G} = x_{r1,G} + F \times (x_{r2,G} - x_{r3,G})
\]
其中 \( r1, r2, r3 \) 是从种群中随机选取的3个不同个体，\( F \in [0.5, 1.0] \) 是缩放因子。

**交叉**（生成试验向量）：
\[
u_{j,i,G} = \begin{cases}
v_{j,i,G}, & \text{if } rand(0,1) \le CR \text{ 或 } j = j_{rand} \\
x_{j,i,G}, & \text{otherwise}
\end{cases}
\]
其中 \( CR \in [0.8, 1.0] \) 是交叉概率。

**选择**：
\[
x_{i,G+1} = \begin{cases}
u_{i,G}, & \text{if } fitness(u_{i,G}) \ge fitness(x_{i,G}) \\
x_{i,G}, & \text{otherwise}
\end{cases}
\]

### 5.3 约束处理（边界约束）

对于变异后超出边界的变量，执行**镜像反射**：
\[
v_{j,i,G} = \begin{cases}
2 \times LB_j - v_{j,i,G}, & \text{if } v_{j,i,G} < LB_j \\
2 \times UB_j - v_{j,i,G}, & \text{if } v_{j,i,G} > UB_j
\end{cases}
\]

### 5.4 时间维度的滚动进化

由于本题是7年序贯决策，我们**不将7年方案一次性编码**（会膨胀到7378维），而是采用**贪心滚动策略**：

1. **固定2023年历史**作为初始状态。
2. **进化2024年方案**：个体维度1054，适应度为2024年利润。
3. **将最优2024年方案固化**，写入历史。
4. **进化2025年方案**：个体维度1054，但解码器此时会查询2024年历史进行重茬检查。
5. 重复直到2030年。
6. **总利润** = 2024~2030年各年最优利润之和。

> **论文亮点**：这种方法将7年序贯问题分解为7个独立的单年优化问题，大幅降低了搜索空间，且由于重茬和豆类约束通过历史状态传递，不会丢失时序信息。

### 一、 规则的精确定义（数学语言）

设水浇地第一季的权重向量为 \( \mathbf{w}_{Q1} = [w_{16}, w_{17}, w_{18}, \dots, w_{34}] \)，其中 \( w_{16} \) 对应水稻，\( w_{17} \sim w_{34} \) 对应蔬菜。

**解码器的硬性裁决逻辑如下：**

\[
\text{Mode} =
\begin{cases}
\text{Mode 1（单季水稻）}, & \text{if } w_{16} > 0 \\
\text{Mode 2（两季蔬菜）}, & \text{if } w_{16} = 0
\end{cases}
\]

**配套的面积分配强制执行规则：**

1. **当 \( w_{16} > 0 \)（触发 Mode 1）：**
   - 第一季：水稻的种植面积 **强制等于该地块总面积**（即 \( Area_{16} = S_{plot} \)），且第一季所有蔬菜权重 \( w_{17} \sim w_{34} \) **被解码器无视（直接置零）**。
   - 第二季：该地块 **强制休耕**，所有第二季根菜权重 \( w_{35} \sim w_{37} \) **被无视（直接置零）**。

2. **当 \( w_{16} = 0 \)（触发 Mode 2）：**
   - 第一季：水稻不种，仅从蔬菜权重 \( w_{17} \sim w_{34} \) 中按比例归一化分配面积。
   - 第二季：从根菜权重 \( w_{35} \sim w_{37} \) 中按比例归一化分配面积（且强制只保留权重最大的一种，以满足题目“只种一种”的要求）。

---

### 二、 为什么这条规则是整套方案的灵魂？

1. **它消灭了离散变量**：我们不需要额外设置一个0-1变量来表示“今年是单季稻还是两季菜”。这个决策完全由 `w16` 这个连续实数的**取值区间**（正数区间 vs 零区间）来决定。
2. **它给了差分进化（DE）清晰的寻优梯度**：
