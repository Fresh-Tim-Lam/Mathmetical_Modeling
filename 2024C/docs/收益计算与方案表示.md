## 2. 收益计算模型

### 2.1 确定性收益（问题 1）

设第 t 年（年份 `t`，2024~2030）单元 u 种植作物 j 的面积为 `x_{uj}`（单元 u 上作物 j 的种植面积，亩，`x ≥ 0`，仅当 `j ∈ S_u` 可取非零）。记作物 j 的可种植单元集合 `U_j = {u : j ∈ S_u}`（支持作物集合 `S_u` 见 1.1）。

**对每个作物 j 单独列式**（求和范围 U_j 随作物不同，价格/亩产/成本都按单元取）：

```
Y_j = Σ_{u∈U_j} q_{uj}·x_{uj}              作物 j 总产量
G_j = Σ_{u∈U_j} p_{uj}·q_{uj}·x_{uj}       作物 j 总产值（各产地单价分别计入）
C_j = Σ_{u∈U_j} c_{uj}·x_{uj}              作物 j 总成本

r_j = min(1, D_j/Y_j)                       售出比例（按产量比例，已定口径）

收入_j = G_j·r_j                                       （情形 1：超量滞销）
收入_j = G_j·[r_j + 0.5·max(0, 1 − r_j)]               （情形 2：超量半价）

π_j = 收入_j − C_j                          作物 j 的收益
π   = Σ_j π_j                               总收益 = 各作物收益之和
```

- 未超量时 `r_j = 1`，收入即总产值 `G_j`；
- 智慧大棚·二季的高档单价只在累加 `G_j` 时体现（`p_{uj}` 取档），公式结构不变；
- 成本按作物汇总 C_j 与按单元累加等价（每个 `(u,j)` 记录唯一）。

> 口径说明：
>
> - **聚合维度**：产量 `Y_j`、产值 `G_j`、售出量 `S_j` 按**作物 j** 聚合（超量/滞销判断基于作物级 `D_j`）；成本按单元累加。计算主循环遍历"单元×作物"种植记录，中间量按作物汇总。
> - **滞销/降价分摊口径（已定）**：各产区**按产量比例同比例售出**（售出率 = `min(1, D_j/Y_j)`），超量部分按各产地产值比例分摊损失——题目 `D_j` 为作物级总量、未指定产地优先级，统货销售视为产地无差异。不采用"高价值产地优先售出"的假设（无题目依据且会诱导把高价菜塞进智慧大棚）。
> - **智慧大棚·二季的单独处理**：只需在累加 `G_j` 时使用高档 `p_{uj}`（`G_j = Σ_{普通产区} p_j⁰·q·x + Σ_{智慧大棚·二季} p_j^F·q·x`），收益函数本身不因智慧大棚分叉——价格差异只是系数，不是函数结构；
> - 双区间作物（蔬菜 17~34）的产值按各产地 `p_{uj}` 分别累加进 G_j，再统一乘售出比例——等价于"超量部分按各产地产值比例分摊"，符合滞销/降价的假设；
> - 若同一作物各产地单价恰好相同，上式退化为 `π = Σ_j p_j·S_j − Σ_u Σ_j c_{uj}·x_{uj}`（粮食/食用菌即此情形）。

### 2.2 随机收益（问题 2）

#### (a) 随机因素与年演化规则

设年份 t（2024~2030），`τ = t − 2023`（年份偏移，代码 `revenue.py` 中记为 `u`）。下表中 `ξ` 为波动量（百分数，乘子形式 `(1+ξ)`），`F(lo,hi)` 为波动分布（四种分布之一，见 (b)）。附件2/题目给出的规则：

| 随机因素      | 对象          | 演化规则（第 t 年）                     | 波动来源                |
| --------- | ----------- | ------------------------------- | ------------------- |
| 预期销售量 `D` | 小麦(6)、玉米(7) | 年增长 5%\~10%（复合）：`D_j·(1+ξ)^τ`   | `ξ ~ F(5%, 10%)`    |
| 预期销售量 `D` | 其他作物        | 相对 2023 约 ±5%（独立每年）：`D_j·(1+ξ)` | `ξ ~ F(−5%, 5%)`    |
| 亩产量 `q`   | 全部          | 每年 ±10%（独立每年）：`q·(1+ξ)`         | `ξ ~ F(−10%, 10%)`  |
| 种植成本 `c`  | 全部          | 平均年增 5%（确定性趋势）：`c·1.05^τ`       | —                   |
| 销售价格 `p`  | 粮食(1\~16)   | 基本稳定：`p`                        | —                   |
| 销售价格 `p`  | 蔬菜(17\~37)  | 年增约 5%（复合）：`p·(1+0.05)^τ`       | 确定性（或 `ξ~F(0,10%)`） |
| 销售价格 `p`  | 食用菌(38\~40) | 稳中有降：`p·(1+ξ)^τ`                | `ξ ~ F(−5%, −1%)`   |
| 销售价格 `p`  | 羊肚菌(41)     | 年降 5%：`p·0.95^τ`                | 确定性                 |

> 待确认：**亩产量 ±10% 是"每年独立波动"还是"相对 2023 的累积波动"**。本文按"每年独立、情景内逐年重抽"处理（更符合"受气候等因素影响，每年会有变化"的表述）。

#### (b) 四种分布（由波动区间 `[lo, hi]` 生成随机数 `ξ`）

| 分布       | 生成方式                                                                | 备注                    |
| -------- | ------------------------------------------------------------------- | --------------------- |
| 均匀分布     | `ξ ~ U(lo, hi)`                                                     | 区间内等概率                |
| 三角分布     | `ξ ~ Tri(lo, (lo+hi)/2, hi)`                                        | 众数取区间中点               |
| 高斯分布（3σ） | `ξ ~ N(mid, σ)`，`mid=(lo+hi)/2`，`σ=(hi−lo)/6`，截断到 `[lo, hi]`        | 3σ≈区间半宽，即 99.7% 落在区间内 |
| 逻辑斯蒂映射（logit-正态） | `η ~ N(0, σ')`（σ' 默认 1，可设定），`ξ = lo + (hi−lo)·sigmoid(η)` | 先经 logit 逆变换把有界区间 `[lo,hi]` 双向映射到无限实轴（`η = ln((ξ−lo)/(hi−ξ))`），在实轴上按正态采样，再经 sigmoid 映射回区间；支撑天然限于 `(lo,hi)`，无需截断 |

> 实现时四种分布共用同一套波动区间表，`profit_stoch` 的 `dist` 参数为分布函数或名称（见 §0），切换即可对比结果。
>
> logit-正态的 σ' 是"设定方差"的自由参数：σ' 越大，映射回区间后越接近均匀（两端概率越大）；σ' 越小越聚拢在区间中点。默认 σ'=1（标准 sigmoid 尺度），若要与高斯 3σ 口径对齐可调大（如 σ'=2 时 sigmoid(±3σ')≈0.998，区间基本被填满）。

#### (c) 期望收益 = 分布函数积分（非蒙特卡洛）

期望收益定义为对**所有波动参数**联合分布的积分（按用户口径，不用 MC 抽样平均）。核算以**（地块-作物）**为粒度逐项代入波动：产量（乘亩产量波动）→ 产值（乘售价波动与售出系数）→ 成本（确定性年演化）→ 收益，最后对波动积分：

```
第 t 年，单元 u（地块-季次）上种植作物 j，面积 x_{uj}：

  ① 产量（乘亩产量波动）：   Y_{uj} = q_{uj}·x_{uj}·(1+ξ_qj)
     作物级总产量：         Y_j    = Σ_u Y_{uj}        （滞销判断基准，作物级 D_j）
  ② 非滞销/总产比（作物级，各产区同比例售出）：
      S_j = min(Y_j, D_j·g_j(ξ_s))               非滞销量 = min(总产, 波动后需求)
      r_j = S_j / Y_j = min(1, D_j·g_j(ξ_s)/Y_j)   非滞销/总产比（r_j ≤ 1 恒成立）
      产值系数 ψ(r_j) = r_j + κ·(1−r_j)             κ=0（mode1 滞销全丢）/ κ=0.5（mode2 滞销半价）
      （因 r_j ≤ 1，(1−r_j) ≥ 0 恒成立，公式统一，无需按情形分写；无滞销时 r_j=1，滞销项自动为 0）
  ③ 产值（乘售价波动 × 售出系数）：
      收入_{uj} = q_{uj}·x_{uj}·(1+ξ_qj)·p_{uj}·(1+ξ_pj)·ψ(r_j)
  ④ 成本（确定性年演化，无随机项）：
      C_{uj}   = c_{uj}·x_{uj}·1.05^τ
  ⑤ 总收益：π = Σ_{u,j} 收入_{uj} − Σ_{u,j} C_{uj}

期望（对联合分布积分）：
  E[π(X_t)] = ∫∫∫ π(X_t, ξ_q, ξ_p, ξ_s)·f_q(ξ_q)·f_p(ξ_p)·f_s(ξ_s) dξ_q dξ_p dξ_s
```

其中 `ξ_qj/ξ_sj/ξ_pj` = 作物 j 的亩产量/销量/价格波动量（乘子 `(1+ξ)`），`f_q/f_s/f_p` = 对应概率密度，`E[·]` = 期望算子，`D_j·g_j(ξ_s)` = 波动后预期销量（`g_j` 为销量演化乘子：小麦/玉米 `g_j=(1+ξ)^τ`，其余 `g_j=1+ξ`），`c_{uj}·1.05^τ` = 波动后成本（无随机项）。

各波动参数在核算过程中的角色（波动**进入计算的位置**）：

| 波动参数  | 进入计算的位置                                    | 分布 / 取值                                   |
| ------ | ------------------------------------------- | ------------------------------------------ |
| `ξ_qj` | 亩产量：`Y_j = Σ_ts q·X·(1+ξ_qj)`，并进入滞销率 `r_j` 的分母 | 全部作物 `F(−10%, 10%)`，独立每年                 |
| `ξ_sj` | 预期销量：`D_j·g_j(ξ_s)`，进入滞销率 `r_j` 的分子           | 小麦/玉米 `(1+ξ)^τ`（ξ~F(5%,10%)）；其余 `1+ξ`（ξ~F(−5%,5%)） |
| `ξ_pj` | 售价：产值 `G_j` 乘 `(1+ξ_pj)`                    | 粮食/蔬菜/羊肚菌确定性（1 / 1.05^τ / 0.95^τ）；食用菌 `(1+ξ)^τ`（ξ~F(−5%,−1%)） |
| 成本     | `C·1.05^τ`，**无随机项 → 提出积分号外**              | 确定性年增 5%                                |

其中 `r_j = min(1, A_j·g_j(ξ_s)/(1+ξ_qj))`（非滞销/总产比，随 ξ_q、ξ_s 变化），`Ȳ_j = Σ_ts q·X` 为基准产量（无波动），`A_j = D_j/Ȳ_j` 为基准供需比。

**化简到逐作物**（①③ 中 `q·x·(1+ξ_q)` 与 `p·(1+ξ_p)` 只经 `ψ(r_j)`——其仅依赖 `ξ_q`、`ξ_s`——耦合，而 `1+ξ_p` 与 `ξ_q`、`ξ_s` 独立，故可先聚合基准产值 `PX_j` 后分解）：

```
E[π] = Σ_j PX_j·E[1+ξ_pj]·I_j − C·1.05^τ

PX_j   = Σ_ts p_tsj·q_tsj·X_ts                 基准产值（各档位单价×亩产×面积聚合）
r_j(ξ) = min(1, A_j·g_j(ξ_s)/(1+ξ_qj))          非滞销/总产比
ψ(r_j) = r_j + κ·(1−r_j)                        产值系数（κ=0 / 0.5，统一式）
A_j    = D_j / Ȳ_j，Ȳ_j = Σ_ts q_tsj·X_ts       基准供需比

I_j = ∬ (1+ξ_q)·[r_j + κ·(1−r_j)]·f_q(ξ_q)·f_s(ξ_s) dξ_q dξ_s，  r_j 见上
```

- 价格因子 `ξ_pj` 与 `(ξ_qj, ξ_sj)` 独立，`E[1+ξ_pj]` 单列（均匀/三角/正态下可直接解析：E[ξ] = (lo+hi)/2）；
- 每个作物 j 只剩一个 **2 维积分 I_j**（41 个），`min` 在 ξ_s 方向是**分段线性**，分界由 `r_j=1` 解出：`g_j(ξ_s*) = (1+ξ_q)/A_j`（`g_j=1+ξ_s` 时即 `ξ_s* = (1+ξ_q)/A_j − 1`）；mode2 的 `κ(1−r)` 项同分段点。

**实现（分布积分，非抽样）**：

- 内层对 ξ_s 的积分可**解析**（均匀/三角分布下，min 分段一次积出）；外层对 ξ_q 剩一维积分；
- 统一用**确定性求积**（Gauss-Legendre，每维 20~40 节点）算 I_j：节点×密度权重 = 分布积分，无抽样噪声、可复现、精度高于 MC；
- 四种分布共用同一求积骨架，只换密度 f 与积分区间。

> 与蒙特卡洛的关系：MC 只是数值积分的一种随机实现。本模块采用**确定性分布求积**——期望收益无随机噪声、逐作物可分解、可复现；求解器调用同一接口 `profit_stoch`，内部为分布求积。如需尾部风险指标（std/CVaR），可用 MC 抽样独立估计收益分布，不依赖本模块。

**公式版本**（与上述核算流水等价，LaTeX）：

$$
\begin{aligned}
& \text{产量} & Y_{uj}(\xi_q) &= q_{uj}\,x_{uj}\,(1+\xi_{qj}), &
& Y_j(\xi_q) &= \sum_{u} Y_{uj}(\xi_q) \\[4pt]
& \text{波动后需求} & D_j^{(t)}(\xi_s) &= D_j\,g_j(\xi_s), &
& g_j(\xi_s) &= \begin{cases}(1+\xi_{sj})^{\tau}, & j\in\{\text{小麦},\text{玉米}\}\\ 1+\xi_{sj}, & \text{其余}\end{cases} \\[4pt]
& \text{非滞销/总产比} & S_j &= \min\bigl(Y_j,\;D_j^{(t)}\bigr), &
& r_j &= \frac{S_j}{Y_j} = \min\Bigl(1,\;\frac{D_j\,g_j(\xi_s)}{Y_j(\xi_q)}\Bigr) \\[4pt]
& \text{产值系数} & \psi(r_j) &= r_j + \kappa\,(1-r_j), &
& \kappa &= \begin{cases}0, & \text{mode}=1 \text{ 超量滞销}\\ 0.5, & \text{mode}=2 \text{ 滞销部分半价}\end{cases} \\[4pt]
& \text{收入} & R_{uj} &= q_{uj}\,x_{uj}\,(1+\xi_{qj})\,p_{uj}\,(1+\xi_{pj})\,\psi(r_j), &
& C_{uj} &= c_{uj}\,x_{uj}\,1.05^{\tau} \\[4pt]
& \text{总收益} & \pi(\xi) &= \sum_{u,j} R_{uj} - \sum_{u,j} C_{uj} \\[6pt]
& \text{期望} & \mathbb{E}[\pi(X_t)] &= \iiint \pi(\xi)\; f_q(\xi_q)\,f_p(\xi_p)\,f_s(\xi_s)\; \mathrm{d}\xi_q\,\mathrm{d}\xi_p\,\mathrm{d}\xi_s
\end{aligned}
$$

**化简到逐作物**（`R_{uj}` 中 `q\,x\,(1+\xi_q)`、`p\,(1+\xi_p)` 仅经 `\psi(r_j)`（只依赖 `\xi_q,\xi_s`）耦合，且 `1+\xi_p` 独立，故先聚合基准产值 `PX_j`）：

$$
\begin{aligned}
\mathbb{E}[\pi] &= \sum_{j} PX_j \cdot \mathbb{E}[1+\xi_{pj}] \cdot I_j \;-\; C\,1.05^{\tau} \\[4pt]
PX_j &= \sum_{ts} p_{tsj}\,q_{tsj}\,X_{ts}, &
\overline{Y}_j &= \sum_{ts} q_{tsj}\,X_{ts}, &
A_j &= \frac{D_j}{\overline{Y}_j} \\[4pt]
I_j &= \iint (1+\xi_q)\Bigl[ r_j + \kappa(1-r_j) \Bigr] f_q(\xi_q)\,f_s(\xi_s)\;\mathrm{d}\xi_q\,\mathrm{d}\xi_s, &
r_j &= \min\Bigl(1,\; \frac{A_j\,g_j(\xi_s)}{1+\xi_q}\Bigr)
\end{aligned}
$$

> 注：`r_j \le 1` 恒成立（非滞销量不超过总产量），故 `\psi` 无需按情形分写——无滞销时 `r_j=1`，滞销项 `\kappa(1-r_j)=0` 自动消失；`\kappa` 仅取 0 或 0.5 两个常数，对应 mode=1/2。

### 2.3 收益函数：内部显式、调用黑盒（结论）

"显式 vs 黑盒"要分**两个层面**，互不冲突：

- **内部（代码可读性 / 论文公式化）：显式查表**。收益 = Σ(面积 × 亩产量 × 单价) − Σ(成本 × 面积)，`q/c/p` 为静态系数（参数查表），不存在"作物类多态"的 if 分支黑盒（deepseek 对话第 13\~14 条反对的正是这种无谓多态）。`q/c/p` 按 `(单元, 作物)` 查表（智慧大棚→普通大棚、水浇地单季水稻等特例在**加载阶段归一化**），核算函数内为纯算术流水线，可写闭合公式、便于敏感性分析。
- **调用（对求解器）：黑盒适应度**。**启发式算法不要求目标函数可导、线性或可解析**——求解器只需把 `profit_det(x, mode)` / `profit_stoch(...)` 当作黑盒目标函数，拿到收益数值作为适应度，**完全不需要理解或解析收益函数内部**。与 MILP 不同，无需把收益线性化或用大M 展开（3.9 的 0-1 表达仅为论文引用备用）。

> 结论：收益函数**对内显式、对外黑盒**——求解器零耦合（只管调用拿数值），收益可解释（论文写公式、做敏感性）。两层设计互不冲突，且各自都是最简形式。

## 3. 方案表示

### 3.1 总原则：地块为向量、先选作物后选面积

- **一级决策（选作物）**：每个**物理地块**每季的作物选择 = **0-1 向量**（该季支持集内每位对应一种作物，1=选中）。除题目明示"只能一种"的限制外（如水浇地第二季只能在大白菜/白萝卜/红萝卜中选一种），**同一季可选中多种作物**（附件说明"第一季可种植多种蔬菜"）；
- **二级决策（选面积）**：对每个**选中**的作物分配面积系数 `α ∈ (0,1]`，同一季 `Σα ≤ 1`（不超地块面积；`α=0` 即不选/休耕）；
- 一年方案 = 54 个地块的决策向量；2024~2030 共 7 个年方案。

之所以按"物理地块"而非"82 个单元"编码，是因为 **水浇地、大棚的模式约束绑定在物理地块层面**（见 3.3），拆成独立单元会破坏耦合。

### 3.2 四类地块的向量结构（0-1 选择 + 面积系数）

每个物理地块每季的决策 = `(选择向量 z, 面积向量 α)`，`z_j=1` 表示本季选中作物 j（可多选）：

| 地块·季次            | 一级决策（0-1 选择 z）                        | 二级决策（面积 α）     | 题目限制（附件1 依据）              |
| ----------------- | --------------------------------------- | ---------------- | ------------------------ |
| 单季露天（A/B/C）      | `z ∈ {0,1}^{1..15}`，可多选                 | 每个选中作物一个 `α∈(0,1]`，`Σα≤1` | 只能种粮食类（水稻除外），只能单季（(1)） |
| 水浇地·第一季（D-1）     | `z1 ∈ {0,1}^{{16}∪17..34}`，水稻与蔬菜互斥     | 同上                 | 水稻（单季模式）或多种蔬菜（双季模式）；35~37 只能第二季种（(2)(3)(4)） |
| 水浇地·第二季（D-2）     | `z2 ∈ {0,1}^{35..37}`，`Σz2 ≤ 1`          | 同上                 | 只能大白菜/白萝卜/红萝卜**之一**（(3)） |
| 普通大棚·第一季（E-1）    | `z1 ∈ {0,1}^{17..34}`，可多选               | 同上                 | 可种多种蔬菜（大白菜/白萝卜/红萝卜除外）（(5)） |
| 普通大棚·第二季（E-2）    | `z2 ∈ {0,1}^{38..41}`，可多选               | 同上                 | 只能种食用菌（食用菌仅在秋冬季普通大棚种植）（(5)(6)） |
| 智慧大棚·第一/二季（F-1/F-2） | `z ∈ {0,1}^{17..34}`，可多选            | 同上                 | **两季都只能种蔬菜**（大白菜/白萝卜/红萝卜除外；粮食、食用菌均不能种）（(7)） |

实际种植面积 = `α_j × A_u`（`z_j=0` 时 `α_j=0`，即不种/休耕）。

### 3.3 水浇地：先选作物 → 隐式确定"单季/双季"模式（重点）

附件1 条件限制：

> 水浇地每年可**单季种水稻**或**两季种蔬菜**；若两季种蔬菜，第一季可种**多种**蔬菜 17~34（大白菜/白萝卜/红萝卜除外），第二季只能种 35/36/37 **之一**。

因此水浇地的决策**不需要单独的"模式变量"**，由第一季选择向量 `z1` 隐式决定：

**选择 → 排除 联动规则**（在水浇地地块上，选中某些作物后其余选择即被限制）：

```
R1  第一季选水稻（z1 含 16） → 单季模式：
     排除：z1 不可再含任何蔬菜 17..34；z2 必须为空（D-2 休耕）
R2  第一季选蔬菜（z1 含 17..34 之一） → 双季模式：
     排除：z1 不可含水稻 16；z2 必须从 {35,36,37} 中选恰好一种（D-2 种萝卜/白菜之一）
R3  第二季：z2 在 {35,36,37} 中至多选 1（选了 35 就排除 36、37）
R4  第一季支持集本身不含 35..37（大白菜/白萝卜/红萝卜只能种第二季，附件说明(4)）
R5  z1 = 0 且 z2 = 0 → 该地块全年休耕（单季模式的特例，R2 的"必须"仅当 z1 含蔬菜时生效）
```

> 注：R2 的"z2 必须选恰好一种"按附件"水浇地每年可**单季种水稻**或**两季种蔬菜**"的模式语义执行；若想让第一季蔬菜+第二季休耕也合法，把 R2 改为"z2 至多选 1"即可（求解灵活性 vs 题目语义，待确认）。

示例：

| 地块               | 方案（0-1 选择 + 面积）                    | 解读                     |
| ---------------- | ------------------------------------ | ---------------------- |
| D7（2023 实际：单季水稻） | `z1={16}, α1=1.0`                     | 单季模式，D7-2 空置           |
| D1（2023 实际：双季蔬菜） | `z1={28}, α1=1.0; z2={35}, α2=1.0`    | D1-1 小青菜、D1-2 大白菜（各 1 种） |

> 好处：**模式约束在编码层面天然满足**，求解器无需额外修复，解空间自动排除"单季还种两季""双季第二季种多种萝卜/白菜"等非法组合。

### 3.4 普通大棚、智慧大棚

- 普通大棚：**每年固定两季**。第一季蔬菜选择 `z1 ∈ {0,1}^{17..34}`（可多种，除 35~37）；第二季食用菌 `z2 ∈ {0,1}^{38..41}`（可多种）。两季支持集不相交，天然不重茬。
- 智慧大棚：**每年固定两季蔬菜**，两季选择均 `z ∈ {0,1}^{17..34}`（可多种，不允许 35~37），两季支持集相同 → **跨季/跨年重茬约束有效**（见 3.6）。

### 3.5 面积表示：连续 vs 离散

每个**选中**作物分配一个面积系数 α（`z_j=0` 时 `α_j=0`），同一季满足 `Σα_j ≤ 1`。

| 方案                                    | 说明                    | 适合的搜索方式   |
| ------------------------------------- | --------------------- | --------- |
| (a) 连续 `α ∈ [0,1]`                    | 精确，但搜索维度连续，需数值优化手段    | 差分进化、局部搜索 |
| (b) 离散档位 `α ∈ {0.25, 0.5, 0.75, 1.0}` | 与"面积不宜太小、方便管理"契合，搜索简单 | 遗传算法、模拟退火 |

建议：**默认 (b) 离散档位**（也可 `{0.5, 1.0}`），因为题目要求"种植面积不宜太小、不宜太分散"，且启发式算法对离散编码更友好。选中多个作物时面积在离散档位中拆分（1 个选中 → `α=1.0`；2 个选中 → 各 `0.5`；依此类推，`Σα≤1`）。

### 3.6 多年方案与轮作/豆类约束

一年方案 `X_t`（第 t 年方案 = `{(u,j) → α_j·A_u}`，同季多作物 = 多组键）。2024~2030 全期方案 `X = {X_2024, …, X_2030}`。

**约束一：不重茬**（同一物理地块，相邻两茬的**作物集合不相交**）

- 单季露天：`z(t) ∩ z(t+1) = ∅`（今年选的作物明年都不能再种）
- 水浇地单季：`z1(t) ∩ z1(t+1) = ∅`（水稻不能连年种）
- 水浇地双季：第一季 17~34、第二季 35~37 支持集不相交 → 季内自动满足；跨年第二季(35~37) 与今年第一季(17~34) 也不相交 → 自动满足 → **水浇地双季下重茬约束自动满足**
- 普通大棚：两季支持集不相交 → 自动满足
- 智慧大棚：需同时满足 `z1(t) ∩ z2(t) = ∅`（跨季）且 `z2(t) ∩ z1(t+1) = ∅`（跨年）
- 2023 实际种植作为 2024 年约束的已知输入（2024 年的"前茬"是 2023 年对应地块的作物）

**约束二：三年内至少种一次豆类**（物理地块层面，滚动窗口）

- 豆类 `B = {1..5, 17..19}`
- 窗口：2023\~2025、2024\~2026、…、2028\~2030（6 个滚动 3 年窗口）
- 每个窗口内，该地块至少有一季种豆类（单季露天任一季种 1\~5；水浇地/大棚任一两季中至少一季是 17\~19；水浇地第一季可选豆类蔬菜 17\~19）

**进入求解器的两种处理方式**（可组合）：

1. **罚函数**：目标 = 收益 − λ₁·重茬违反次数 − λ₂·豆类窗口违反次数；
2. **可行化修复**：变异/交叉后对违反约束的地块局部重选作物。

> 讨论点：水浇地如果第 t 年双季、第 t+1 年单季（种水稻），重茬约束只比较"相邻两茬"（上一年第二季 vs 今年第一季），今年第一季种水稻 ≠ 上一年第二季萝卜 → 合法。反之单季→双季也合法。**"不能连续重茬"指相邻两次种植，不是同季节同比**。

### 3.7 由方案向量派生决策变量

```
对第 t 年方案（0-1 选择 + 面积系数 → 面积记录）：
  每个选中作物 j（z_j=1）在对应单元 u 上产生一条记录 x_{u,j} = α_j·A_u；
  同一季多个选中作物 → 多条记录（同季合种天然支持，α_j 各占其面积）。
  单季露天：u 为该地块单元
  水浇地：第一季选中 16 → 单季模式，只产生 D-1 记录（D-2 无）；
          第一季选中 17..34 → 双季模式：D-1 记录 + D-2 按 z2 生成记录
  大棚：第一季 u1、第二季 u2 各自按选择向量生成记录
```

得到的 `x = {(单元, 作物) → 面积}` 直接作为 `RevenueModel.profit(x, params, mode)` 的输入——**dict 多键天然支持同季合种**，收益核算按 (单元, 作物) 逐键累加面积，无需额外改动。

### 3.8 编码规模估计

- 决策块 54 块/年 × 7 年；
- 一级（0-1 作物选择）：单季露天每块 15 位可多选（≈2¹⁵）；水浇地第一季 水稻/蔬菜互斥（1+2¹⁸ 组合）+ 第二季 3 选 1（最多一种）；普通大棚第一季 18 位可多选 + 第二季 4 位可多选；智慧大棚 18 位 × 2 季可多选（含重茬约束后更少）；
- 二级（面积）：每个选中作物 4 档（`Σα≤1`）；
- 解空间规模数量级极大，适合启发式；关键是收益计算要**快**。**同季合种使搜索空间大幅扩大**——求解时可先用"每季选中作物数上限"收缩（如 ≤2，与 2023 实际一致的常见情况），收敛后再放宽对比。

### 3.9 两级分层决策的数学化表达（衔接先前讨论）

先前讨论（deepseek 对话第 43\~44 条消息）确认：**"先选作物类型、后分配面积"正是 0-1 开关 + 面积联动的标准建模逻辑**，水浇地"选作物即定季节"即"类型互斥约束"。严格写法如下（供论文/ MILP 引用）：

对每个物理地块 k、其单元 u、作物 j 定义：

- `y_{k,j} ∈ {0,1}`：一级决策，是否在 k 上选择作物 j（开关）；
- `x_{u,j} ≥ 0`：二级决策，单元 u 上作物 j 的面积（旋钮）。

联动与面积上限（大M 法）：

```
x_{u,j} ≤ A_u · y_{k,j}              （y=0 ⟹ x=0；y=1 ⟹ x ∈ [0, A_u]）
Σ_{j ∈ S_u} x_{u,j} ≤ A_u            （单元面积上限）
```

水浇地"类型互斥"（选水稻则无第二季；选蔬菜则强制第二季萝卜/白菜之一）：

```
Σ_{j ∈ 17..34} y_{k,j} ≤ 1 − y_{k,16}           （一季蔬菜 与 水稻 互斥）
Σ_{j ∈ 35..37} y_{k,j} ≤ M · Σ_{j ∈ 17..34} y_{k,j}   （有蔬菜，第二季才可种萝卜/白菜）
Σ_{j ∈ 35..37} y_{k,j} ≤ 1                       （第二季最多一种）
```

> 说明：这套 0-1 表达**就是方案编码本身**——一级决策 `z_{k,j}∈{0,1}`（1=选择，同季可多选）即 3.1/3.2 的 0-1 选择向量，二级决策 `x_{u,j}=α_j·A_u` 即面积分配，`Σ_j x_{u,j} ≤ A_u` 对应 `Σα_j ≤ 1`。启发式路线的编码层与数学表达同构：`y=0 ⟹ x=0` 在派生（3.7）时天然满足，水浇地"类型互斥"（`Σ_{j∈17..34} y_{k,j} ≤ 1 − y_{k,16}`、第二季 `Σ_{j∈35..37} y_{k,j} ≤ 1`）在生成/变异解时保证。**编码保证可行性，数学表达式与编码同构（论文可直接引用）**。

### 4.1 收益模块内部结构（双主码表硬编码，档位面积矩阵对齐）

```
src/revenue.py
1) 加载 经济参数明细.csv → 档位参数矩阵 T[ts, j] = (q_{tsj}, c_{tsj}, p_{tsj})    # 10×41，与明细表格式完全对齐
2) 单元→档位归属的累计规则（加载期数据处理，ts_map[unit, j]，-1 = 不支持）：
      A*/B*/C* 单元 → A/B/C
      Dx-1：j=16 → D；j∈17..34 → D-1      Dx-2 → D-2
      Ex-1 → E-1；Ex-2 → E-2
      Fx-1 → F-1；Fx-2 → F-2
      （每个单元的面积按此规则**累计**进对应档位行，见 4) 的 to_ts）
3) 销量基准 D_j（作物级，仅此粒度可用）：2023 无销量数据，按"产量=销量"近似，
      由 src/data_prep.crop_sales_2023() 加工：data/2023种植情况.csv（87 条真实记录）
      × data/经济参数明细.csv（档位亩产量）→ Σ 面积×档位亩产量。
      原因：2023 年 87 条种植记录只覆盖 80 个单元、87 个(地块×作物)组合，远小于
      支持集 1062——绝大多数组合无种植数据，拆到单元/档位的"基准"大量为 0，
      这些 0 是"没种过、没数据"而非"该产地卖不掉"，用作独立滞销基准会得到失真
      结果（换作物即"全滞销"），故只能按作物级总量。
4) to_ts(x) 格式处理（方案格式映射函数，收益函数唯一入口）：
      求解过程中方案的格式会因"某种地块/季次不种某些作物"而 vary——
      dict 只含非零项、单元矩阵稀疏、或直接给档位矩阵，统一归一化为
      收益函数可识别的档位面积矩阵 X_ts(10×41)：
      —— 同一档位下所有单元的面积**累计到一行**（与参数矩阵同构，矩阵运算前提）
5) profit_det(x, mode)：在 X_ts 上纯矩阵运算（形状标注）
      X      = to_ts(x)                   档位面积矩阵 [10,41]
      q'     = q·yield_f                  档位参数×作物级因子按列广播 → [10,41]（c'、p' 同）
      Y_j    = Σ_ts (q'·X)  → [41]        作物总产量（沿档位轴累加）
      G_j    = Σ_ts (p'·q'·X) → [41]      作物总产值
      C      = Σ (c'·X) → 标量            总成本
      r_j    = min(1, D_j/Y_j) → [41]     售出比例（作物级，各产区同比例）
      收入   = Σ_j G_j·r_j（mode2 加半价）→ 标量
      π      = 收入 − C → 标量
6) profit_stoch(x, year, dist, mode)：
      2.2(a) 年演化 × 2.2(c) 分布求积：对每个作物 j 算二维积分 I_j
      （Gauss-Legendre 确定性求积，内层对 ξ_s 分段解析，外层对 ξ_q 求积）
      → 逐作物累加得 E[π]（无随机噪声、可复现）
```

> 关键点：**决策方案与参数表对齐**是矩阵加速的前提——`X_ts[10,41]` 与参数矩阵同构，同一档位（地块类型·季次）下的全部单元面积先累计成一行，产量/产值/成本等线性量沿档位累计后在作物轴求和，核算全程无逐单元循环、无 I/O、无分支特例（所有映射在加载期归一化）；`profit_det` 是**唯一核心核算函数**，`profit_stoch` 只做"逐作物积分循环 + 聚合"一层薄封装。这样问题1/2/3 共用一套硬编码参数，收益口径完全一致。已用 2023 实际种植验证：档位矩阵(10×41)核算结果 = 展开单元(82×41)核算结果（2023 收益 592.63 万元）。

### 4.2 收益计算流水线（单次核算）

输入：方案 `x`（`dict{(单元, 作物编号): 面积}` 或单元矩阵/档位矩阵）、情景参数 `params`、`mode`（1=超量滞销 / 2=超量半价）。分**加载期**与**每次核算**两段：

```
┌─ 加载期（RevenueModel.__init__ 只做一次）─────────────────────────┐
│ P1  经济参数明细.csv → 档位参数矩阵 T[10,41]：(q, c, p)            │
│     非支持集位置补 0（nan→0，防 0×nan 污染求和），全表矩阵化         │
│ P2  单元→档位归属的累计规则 ts_map[82,41]（-1=不支持）             │
│     （水浇地单季水稻→D、F-1 独立档 等特例在加载期归一化）             │
│ P3  作物级销量基准 D_j ← data_prep.crop_sales_2023()             │
│     = Σ 2023 种植面积 × 档位亩产量（作物级向量，仅此粒度可用）        │
│ P4  波动规则 ← 经济数据.csv（wave_yield/wave_price/wave_sales）    │
└─────────────────────────────────────────────────────────────────┘

┌─ 单次核算（profit_det / 每个情景）───────────────────────────────┐
│ S1  格式处理 to_ts(x)（方案格式映射，收益函数唯一入口）：          │
│     dict{(单元,作物):面积}（只含非零）→ 单元面积矩阵(82×41)          │
│     → 按 ts_map 把同一档位所有单元的面积**累计到一行**               │
│     → X_ts[10,41]（与参数矩阵同构）                              │
│ S2  确定性参数（问题1 各因子=1，无波动）：直接用档位参数 q/p/c，      │
│     滞销基准 D_j = 2023 作物级总量                                  │
│ S3  矩阵累计（沿档位轴求和 → 作物级向量）：                          │
│     Y_j = Σ_ts (q·X_ts)          作物 j 总产量                     │
│     G_j = Σ_ts (p·q·X_ts)        作物 j 总产值（各档位单价分别计入）  │
│     C   = Σ (c·X_ts)             总成本（标量）                    │
│ S4  滞销率（作物级，各产区同比例售出）：                             │
│     r_j = min(1, D_j/Y_j)        （Y_j=0 处置 1，无产值无害）        │
│ S5  收入与收益：                                                  │
│     mode1  收入 = Σ_j G_j·r_j                                     │
│     mode2  收入 = Σ_j G_j·(r_j + 0.5·max(0, 1−r_j))               │
│     π = 收入 − C                                                 │
└─────────────────────────────────────────────────────────────────┘
```

- **问题 1**：`profit_det(x, mode)` 即 S1~S5（确定性：各因子=1，`D_j`=2023 基准）。
- **问题 2/3**：`profit_stoch` 按 2.2(c) 做**分布求积**（非 MC）——期望由确定性积分得到：

```
profit_stoch(x, year, dist, mode):
  Ȳ_j ← 基准产量（作物级，来自方案 X_ts 与 q）
  A_j ← D_j/Ȳ_j                                # 基准供需比
  for j in 1..41:                              # 各作物独立 → 逐作物积分
    I_j ← ∬ (1+ξ_q)·min(1, A_j·(1+ξ_s)/(1+ξ_q))·f_q·f_s dξ_q dξ_s
          # Gauss-Legendre 求积：内层 ξ_s 分段解析，外层 ξ_q 求积（40 节点）
  E[G_j·r_j] ← (Σ_ts p·q·X)·E[1+ξ_pj]·I_j
  return Σ_j E[G_j·r_j] − C                    # 确定性期望（无抽样噪声）
```

> 流水线要点：**滞销/降价是非线性（min/分段）**，必须在作物级 `r_j` 计算——但产量/产值/成本是线性量，可先沿档位累计再在作物轴求和，因此只需 `X_ts[10,41]` 一级聚合即可对齐公式 2.1；求解器黑盒调用 `profit_det/profit_stoch` 拿到标量收益，无需了解内部流水线。
